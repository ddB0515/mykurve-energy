## Configuration

During setup you'll be asked for your MyKurve username and password. If your
MyKurve account has 2FA enabled, also provide the 2FA secret (the base32 code
shown when you set up 2FA on mykurve.com, not a one-time code) in the
"2FA secret" field — the integration generates codes from it automatically on
every login/token refresh. Leave it blank if your account doesn't use 2FA.
